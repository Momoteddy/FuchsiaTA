# FuchsiaTA

For anyone viewing this today, the files above are for the frontend (to be installed on the user's desktop). It relies on a backend hosted on Render to handle all the API calls, store data securely, handle user authentication, etc. As of a few months after finishing our final defense, the backend no longer works since it ran on Render's free tier, which eventually deletes your code after a while has passed.

I still have the backend on my laptop, but by this point even rehosting it somewhere else wouldn't work anymore since my API credits have long expired. I don't know what works without the backend; I don't think you'll be able to get past the login screen even with the right credentials lol.
